What Are Vector Graphics?

Vector graphics use mathematical equations — points, lines, curves, and shapes — to represent images. Unlike pixel-based images, they can be scaled to any size without losing quality.

Anatomy of a Vector

Every vector image is built from these core elements.

Points

Anchor locations defined by x,y coordinates.

Paths

Straight or curved lines connecting points.

Curves

Bézier handles that shape smooth arcs.

Shapes

Closed paths that form recognisable figures.
